# Produção Técnica

## Softwares Desenvolvidos

### SASC - Sistema de Gestão para Cooperativas de Crédito

Software para gestão de processos, produtos e serviços de Cooperativas de Créditos. Implementado para plataformas Windows e Web (SASC WEB). Módulos do sistema: Associado, Atendimento, Empréstimos, Crédito Rural, Produtos, Seguros, Plano de Saúde, Consórcios, Comissões, Cobrança, Contabilidade, Tarifas e Ferramentas Administrativas.

### Supernova Educação

Software para gestão de unidades educacionais focadas em cursos especializados e preparação para concursos.  Módulos para gestão de alunos, controle de ambientes, salas e turmas, gestão financeira e serviços.

### GeFIN Gestão Financeira

Sistema para planejamento e gestão de recursos financeiros aplicados pelo governo federal em projetos de educação à distância, com foco para a Universidade Aberta do Brasil (UAB) em parceria com a Universidade Estadual de Montes Claros. Módulos: Projetos, Licitações, Planilha Orçamentária, Financeiro, Solicitações Diversas, Diárias e Locações, Administraçõo de Bolsas e Pessoas.

### SGR Gestão de Rotas

Software para planejamento, gestão e controle de: roteiros de viagens, diárias, veículos, motoristas e empresas terceirizadas no contexto de servidores da educação atuantes em pólos de educação à distância. 

### ClinMED Clínicas Médicas

Sistema de informação para gestão de clínicas médicas. Módulos: pacientes, agenda, gestão financeira, recursos humanos e almoxarifado.

### Bússola

Software para administração de planos corporativos de telefonia celular e automatização do processamento de faturas individuais e gestão de franquias.
