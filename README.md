# Produção Técnica

## Softwares Desenvolvidos

### SASC - Sistema de Gestão para Cooperativas de Crédito

Software para gestão de processos, produtos e serviços de Cooperativas de Créditos. Implementado para plataformas Windows e Web (SASC WEB). Módulos do sistema: Associado, Atendimento, Empréstimos, Crédito Rural, Produtos, Seguros, Plano de Saúde, Consórcios, Comissões, Cobrança, Contabilidade, Tarifas e Ferramentas Administrativas.

### Supernova Educação

Software para gestão de unidades educacionais focadas em cursos especializados e preparação para concursos.  Módulos para Gestão de Alunos, Controle de Ambientes, Salas e Turmas, Financeiro e Serviços.

### GeFIN Gestão Financeira

Sistema para planejamento e gestão de recursos financeiros aplicados pelo governo federal em projetos de educação à distância, com foco para a Universidade Aberta do Brasil (UAB) em parceria com a Universidade Estadual de Montes Claros. Módulos: Projetos, Licitações, Planilha Orçamentária, Financeiro, Solicitações Diversas, Diárias e Locações, Administraçõo de Bolsas e Pessoas.

### SGR Gestão de Rotas

Software para planejamento, gestão e controle de Roteiros de viagens, Diárias, Veículos, Motoristas e Empresas terceirizadas no contexto de servidores da educação atuantes em pólos remotos de educação à distância. 

### ClinMED Clínicas Médicas

Sistema de informação para gestão de Clínicas Médicas. Módulos: Pacientes, Agenda, Gestão Financeira, Recursos Humanos e Almoxarifado.

### Bússola

Software para administração de planos corporativos de telefonia celular e automatização do Processamento de Faturas e Gestão de Franquias.

### Gestão de Requerimentos / IFNMG Campus Januária

Sistema WEB para gestão de Requerimentos Discentes ao Departamento de Ensino Superior do IFNMG campus Januária. Antes realizado de forma manual, possibilitou informatizar todos os trâmites administrativos, desde o cadastro, encaminhamentos aos órgãos competentes, resultados, notificação e arquivamento.
